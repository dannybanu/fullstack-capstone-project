#User Stories

Finish defining user stories #1
As a product owner
I need all user stories to be clearly defined
So that the development team understands the full scope of the project.

Initialize and populate MongoDB #2
As a developer
I need to set up and populate MongoDB
So that the application has initial data to work with.

Run skeleton application #3
As a developer,
I want to run the base application,
So that I can verify the initial setup works correctly.

Implement landing page and navigation #4
As a user,
I want a landing page with navigation,
So that I can easily move through the app.

Implement authentication #5
As a user,
I want to register and log in,
So that I can access protected features.

Gifts details page #6
As a user,
I want to view details of a gift,
So that I understand its information.

Search functionality #7
As a user,
I want to search for gifts,
So that I can find items quickly.

Comments system #8
As a user,
I want to add comments to gifts,
So that I can share feedback.

Containerize application #9
As a developer,
I want to containerize the app,
So that it runs consistently across environments.

Deploy application #10
As a user,
I want the application to be deployed,
So that I can access it online.

Research authentication in React and Express #11
As a developer,
I want to research authentication in React and Express,
To implement a correct and secure solution.
